E-Commerce Multi-Region India → UAE · Apparel

Taking a Regional Apparel Brand to a Multi-Country Online Store

Problem Statement

Existing WooCommerce store loaded in 8+ seconds on mobile, had no multi-currency capability, ran on shared hosting that crashed during sales events, and had no WMS integration — causing overselling and massive customer service overhead.

System Architecture

Headless WooCommerce backend → Next.js frontend on Vercel with AWS CloudFront CDN. Custom REST API sync with WMS. Stripe multi-currency with geolocation detection. Regional subdirectory (/ae/) with Arabic language toggle.

Education / EdTech LMS Build Pan-India · 12,000 Students

Custom LMS for a Pan-India Competitive Exam Coaching Institute

Problem Statement

12,000 students with content on public YouTube, PDFs via WhatsApp, and Zoom with no recording management. No student dashboard, no assessment system, no progress tracking, and content being shared externally.

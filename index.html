E-Commerce Multi-Region India → UAE · Apparel

Taking a Regional Apparel Brand to a Multi-Country Online Store

Problem Statement

Existing WooCommerce store loaded in 8+ seconds on mobile, had no multi-currency capability, ran on shared hosting that crashed during sales events, and had no WMS integration — causing overselling and massive customer service overhead.

System Architecture

Headless WooCommerce backend → Next.js frontend on Vercel with AWS CloudFront CDN. Custom REST API sync with WMS. Stripe multi-currency with geolocation detection. Regional subdirectory (/ae/) with Arabic language toggle.

Education / EdTech LMS Build Pan-India · 12,000 Students

Custom LMS for a Pan-India Competitive Exam Coaching Institute

Problem Statement

12,000 students with content on public YouTube, PDFs via WhatsApp, and Zoom with no recording management. No student dashboard, no assessment system, no progress tracking, and content being shared externally.

E-Commerce Multi-Region India → UAE · Apparel

Taking a Regional Apparel Brand to a Multi-Country Online Store

Problem Statement

Existing WooCommerce store loaded in 8+ seconds on mobile, had no multi-currency capability, ran on shared hosting that crashed during sales events, and had no WMS integration — causing overselling and massive customer service overhead.

System Architecture

Headless WooCommerce backend → Next.js frontend on Vercel with AWS CloudFront CDN. Custom REST API sync with WMS. Stripe multi-currency with geolocation detection. Regional subdirectory (/ae/) with Arabic language toggle.

Real Estate AI Integration Dubai, UAE · 30 Agents · 600–800 Inquiries/Month

AI-Powered Lead Management for a Dubai Real Estate Agency

Problem Statement

600–800 inquiries/month across website, WhatsApp, and property portals with no unified system. Agents managed leads through personal WhatsApp. No lead source visibility, no conversion tracking, high-intent buyers lost in the noise.

System Architecture

Custom property listing site → HubSpot CRM as central lead database. All channels (website, WhatsApp Business API, portal imports) routed to single inbox. AI chatbot (Claude API + RAG on Pinecone) trained on listings and market FAQs. Bilingual Arabic/English throughout.

Education / EdTech LMS Build Pan-India · 12,000 Students · Coaching Institute

Custom LMS for a Pan-India Competitive Exam Coaching Institute

Problem Statement

12,000 students with content on public YouTube (no access control), PDFs via WhatsApp, and Zoom with no recording management. No student dashboard, no assessment system, no progress tracking, no way to measure learning outcomes. Content shared externally with no recourse.

System Architecture

Custom LMS on Node.js + React, deployed on AWS with CloudFront CDN. Video delivered via Bunny.net with signed URL expiry. Hierarchical course structure with access control. Timed assessment module. WhatsApp API for reminders. Razorpay for enrollment.
